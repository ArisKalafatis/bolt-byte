Pick your path

Which competition is for you?

FIRST has a program for almost every age. We help you choose, then get you ready.

FLL

FIRST LEGO League

Ages 9–16. Build and program LEGO robots to solve missions, and present an innovation project.

FTC

FIRST Tech Challenge

Middle and high school. Design, build and code a mid-size robot for a themed alliance game.

FRC

FIRST Robotics Competition

High school. Industrial-size robots, big events and a team that runs like a small company.
